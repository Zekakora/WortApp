# WortApp 学习使用指引

> 面向使用者的操作建议。核心目标：**如实评分 + 合理设置**，让 SM-2 间隔重复
> 算法把复习安排在你「快要忘记」的时候，从而用最少的时间记住最多单词。
>
> 算法原理详见 [ALGORITHM.md](ALGORITHM.md)。

---

## 一、评分怎么选（最重要）

每次答题后会出现四个按钮。评分直接决定这个词**下次什么时候再出现**，
所以**如实评分最有利于长期记忆**——为了心软给高分，词会很快消失、又很快忘。

### 四个按钮的含义

| 按钮 | 什么时候选 | 算法效果 |
|------|-----------|---------|
| **忘记** | 完全想不起来 / 答错 | 明天再复习；重复进度清零；进入错词重考 |
| **模糊** | 有印象，但没答对或答不全 | 明天再复习；进度保留、难度略升；进入错词重考 |
| **熟悉** | 基本答对了，稍有停顿 | 按正常节奏延长复习间隔（默认选择） |
| **简单** | 秒答、毫不费力 | 间隔延长更多（要少用） |

要点：
- **「模糊」并不轻**——它会让这个词明天再来一遍并降低难度评级；
  所以它适合「没答对/答不全」，不适合「答对了但有点犹豫」。
- **答对但有点犹豫 → 用「熟悉」**，这是每天大多数情况的选择。
- **「简单」要少用**：它每次都会把间隔拉得更长，容易造成"自我感觉良好但过几天全忘"。

### 常见情况怎么选

| 你的情况 | 建议 |
|----------|------|
| 完全不会 / 认不出 | **忘记** |
| **知道词义，但忘了冠词/词性（der·die·das）** | **模糊** |
| **忘了复数 / 第二格 / 动词变位** | **模糊** |
| 靠排除法、上下文或运气猜对 | **模糊** |
| 拼写错但能认出 / 听音听不出 | **模糊** |
| 基本都对，只是略慢、略犹豫 | **熟悉** |
| 一眼就会、毫不费力 | **简单** |

> **德语名词特别提醒**：名词离开冠词几乎不成立，建议**把冠词一起记牢**再给
> 「熟悉」。只记得词义、记不清 der/die/das 时，用「模糊」，让它明天再练。

### 为什么要如实评分

- 给高分 → 间隔变长 → 下次见面时可能已经忘了，等于白学。
- 给低分 → 出现更频繁 → 虽然短期"烦"，但记忆更牢。
- 答错（忘记/模糊）会进入**错词重考**并计入**错误统计**，帮助你发现薄弱词。

## 二、学习设置怎么用

学习页（"选择学习模式"）顶部可以设置以下参数，它们会影响抽词与调度。

### 每轮单词数

一次学习会话包含多少个单词（默认 20，可选 10 / 20 / 50 / 自定义）。
适合按当天可支配的时间调整。

### 抓词模式

| 模式 | 用途 |
|------|------|
| **正常抓词** | 按每日上限正常抽取「新词 + 到期复习词」 |
| **收藏优先** | 收藏的词优先出现在本次学习中 |
| **只抓收藏** | 只练习已收藏的词（适合专攻重点词） |
| **今日错词** | 只练习今天答错过（忘记/模糊）的词；答错会重排再复习，连续 3 轮首答正确才移出 |

### 只复习（开关）

- **开启**：本次学习**不抽取任何新词**，只复习「今天到期的词」；
  如果今天没有到期词，就循环复习「今天已学过的词」。
- **关闭**：按每日上限正常抽取新词与复习词。
- 适合"今天不想加新词、只想巩固"的日子，或考前一天集中复习。

### 随机背词（开关）

- **开启**：抽词时打乱顺序，不按单词本顺序抽取。
- **关闭**：按单词本顺序依次抽取。

> 建议开启：打乱顺序能避免"靠位置顺序回忆"的假象。

### 每日新词 / 复习上限

在**设置页**配置（默认新词 20 / 复习 100）。到达上限后不会再抽新词，
会进入下面的"循环复习"。合理设置可以防止某天单词量过载。

### 循环复习（额度用尽后）

当今天的新词与到期复习词都用完（或开启"只复习"且没有到期词）时：
App 会自动**循环复习今天已学的单词**——每次学习发放一批（每轮单词数），
分批覆盖今天全部单词，覆盖完毕后自动开启下一大轮，轮数无上限。
进度会自动保存，中途退出后再进入会接着学，不重复、不遗漏。

### 错词重考

正常模式下答错（忘记/模糊）的单词，会在学完主列表后**重新出现**让你再答一遍：
答对移出、再错回到队尾，最多重考 2 次（避免无限循环）。

## 三、快闪卡模式怎么评分

快闪卡是全屏限时卡片，用**滑动**代替按钮：

- **左划 = 忘记**
- **右划 = 已想起**（红灯亮起前）；**红灯亮起后再右划 = 模糊**
- **上滑 = 查看单词详情**

灯条表示时间：绿（回忆中）→ 黄（揭示释义）→ 红（还没想起）。

## 四、小贴士

1. **每天坚持一小会儿**比周末突击更有效——间隔重复靠的就是"少量多次"。
2. **不确定就给"模糊"**，宁可多复习一次，也不要虚假掌握。
3. 结合**变位练习**与**单词详情**（冠词/复数/变位）一起记，效果更好。
4. 列表里的**熟练度星标**反映该词在 SM-2 中的掌握程度，越高越稳固。
