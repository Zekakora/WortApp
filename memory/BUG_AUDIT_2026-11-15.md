分支：`fix/search-deck-flow`（从 `master@4601289` 切出，**master 未改动**）

## 一、已修复

### 1. 严重：查词 →「加入词书」→「新建词书」→ 黑屏

**根因**：`showModalBottomSheet` 之上再 `showDialog`，形成「页面 → 底部弹窗 → 对话框」三层路由；
创建词书时用对话框自己的 `context` 连做两次 `Navigator.pop` 关闭对话框与弹窗，
随后又把同一个已失效的 `context` 传给入库方法，入库方法里还有第三次 `Navigator.pop`。
`AppNavigation` 是 `MaterialApp.home`，**整个 App 只有一个根路由**，多 pop 一次就把根页面弹掉，
路由栈清空 → 黑屏（无内容可绘制）。

**修复方式**（`lib/ui/screens/search/search_screen.dart`）：

- 新增 `_findExistingWord()`：查重逻辑从入库方法里抽出，新建词书前也能先查重。
- `_addToDeck()` 改为纯业务方法：只入库 + 用**提前取出的 `ScaffoldMessengerState`** 提示，
  不再 `Navigator.pop`（谁打开的弹窗谁关闭）。
- 删除 `_createAndAdd()`（对话框叠弹窗的写法），改为 `_createDeckAndAdd()`：
  返回 `bool` 表示是否处理完成，由面板决定是否关闭自己。
- `_DeckSelectionSheet` 由 `ConsumerWidget` 改为 `ConsumerStatefulWidget`：
  「新建词书」改为**面板内联表单**（输入框 + 「创建并添加」），彻底消除多层弹窗；
  增加空名校验、提交中禁用、失败保持展开可重试、列表项加号提示、空状态引导按钮、
  底部安全区内边距、长词书名单行省略。
- 同名工具书复用：输入的书名已存在时直接复用该词书，不再产生两本同名书。

**验证**：`test/add_to_deck_flow_test.dart`（5 个用例，全部通过）
覆盖：新建词书不黑屏并入库、空名报错不建书、直接选已有词书、单词已存在不重复添加、
同名词书复用。修复前第 1 个用例会因根路由被 pop 而失败。

### 2. 深色主题缺按钮 / 标签主题（浅深色观感不一致）

`lib/core/theme/app_theme.dart`：`darkTheme()` 缺 `filledButtonTheme`、`outlinedButtonTheme`、
`chipTheme` 与 `navigationBarTheme.labelTextStyle`，导致切到夜间模式后按钮圆角/内边距、
底部导航标签字重都会变样。已补齐，与浅色主题一致。

### 3. 词性筛选弹窗小屏溢出

`lib/ui/screens/deck/word_list_screen.dart`：9 个 `ListTile`（约 500dp）+ 标题/按钮，
放在不可滚动的 `AlertDialog.content` 里，小屏/大字号下会出现溢出条纹。
已改为 `SingleChildScrollView`，并把 9 段重复代码收敛成表驱动渲染。

### 4. 首页词书切换面板高度跳动

`lib/ui/screens/home/home_screen.dart`：`loading` 用裸 `Center(child: CircularProgressIndicator())`
会撑满面板，数据到达后面板高度骤降；已改为固定高度占位。
同时 `setActiveDeck()` 改为 `await` 后再关面板，避免「已切换但仍显示旧词书」。
词书名/描述加单行省略，长名不再挤压。

### 5. 首页今日进度卡片加载态

`lib/ui/screens/home/widgets/progress_card.dart`：裸 `CircularProgressIndicator`
在自适应 Column 里被拉成整行宽、高度突变；改为 24×24 左对齐。

### 6. 设置页 AI 配置弹窗

`lib/ui/screens/settings/settings_screen.dart`：原本把 6 个服务商的 baseUrl 当灰色文字逐行堆着；
改为可点击的 `ActionChip` 预设（点一下填入地址 + 模型），灰色小字改用 `onSurfaceVariant`。

## 二、发现但未改动（需你确认优先级）

1. **静默失败**：`deck_list_screen.dart:1022` 新建词书时 `createDeck()` 未 `await` 就
   `Navigator.pop()`，插入失败（如重名）时对话框已关、用户看不到任何提示。
   建议 `await` + try/catch + SnackBar。
2. **脆弱的双 pop**：`word_detail_screen.dart:1164-1170` 删除单词后用对话框的 `context`
   连 pop 两次（关对话框 + 退页面）。当前栈顺序正确，但一旦中间插入别的路由就会弹错页面，
   建议先关对话框、再由页面自己 `Navigator.of(context).pop()`。
3. **加载对话框可能卡死**：`deck_list_screen.dart:315`、`settings_screen.dart:580` 等处
   「showDialog 加载中 → await 长任务 → context.mounted 才 pop」；
   若用户在导入/导出过程中离开页面，加载对话框会永久留在屏上。
   建议持有一个独立的 `NavigatorState`/`GlobalKey` 或用 `showDialog` 返回的 Future 统一收尾。
4. **设置语义不一致**：`settings_provider.dart:353-366` 关闭「查词后自动加入词书」时
   不清空 `autoAddToDeckId`，开关关闭后目标词书 ID 仍残留。
5. **深色模式配色**：`cn_to_de_screen.dart:262/264`、`de_to_cn_screen.dart:294/296`、
   `listen_mode_screen.dart:295/297`、`spell_mode_screen.dart:266` 用
   `Colors.green.shade100 / red.shade100` 作答题底色，夜间模式下偏亮刺眼；
   建议改用 `colorScheme` 的语义色（或 `AppColors` 提供 success/error 容器色）。
6. **灰色小字对比度**：多处 `TextStyle(color: Colors.grey)`（`onedrive_sync_section.dart:67/95`、
   `batch_update_dialog.dart:139/145`、`import_dialog.dart:184/300`、
   `conjugation_screen.dart:671/677`、`conjugation_data_manager_screen.dart:692/698`、
   `batch_task_widgets.dart:247`），浅色下对比度约 2.8:1，不达 WCAG AA；
   统一改 `colorScheme.onSurfaceVariant` 即可。
7. **依赖漂移（环境行为，非本次改动）**：`flutter analyze` 触发的 `pub get` 重新解析了
   `pubspec.lock`（137 个包变动，如 sqlite3 2.9.4 → 3.5.2）。当前 `dart analyze` 与
   全部 243 个测试均通过，但如需与已发布版本的依赖完全一致，建议核对 `pubspec.lock`。
